# roomcopy
O RoomCopy é uma extensão em Python (G-Earth) para automação no Habbo Hotel. Criado para o Clube do Arquiteto, clona quartos inteiros com precisão: mapa do chão, mobis, itens de parede, alturas empilhadas (Stacks) e estados (states). Conta com filtros para ignorar Wireds, sistema de presets em JSON e interface gráfica bilíngue.
